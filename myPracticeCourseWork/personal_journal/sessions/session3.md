## Summary of learning
Learned how DHCP automatically assigns Ip addresses, subnet masks, default gateways and DNS servers based on the MAC address of the user. Learned about the difference between static and dynamic ip allocation. Learned how DNS translates readable names into IP addresses that the system can read. Used dnsmasq to apply DHCP and DNS to lab machines.
